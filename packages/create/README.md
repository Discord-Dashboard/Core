# @asctane-dashboard/create

Scaffold a new asctane-dashboard project.

```bash
npm init @asctane-dashboard@beta my-bot
```

Creates a discord.js bot with a dashboard: `index.js`, `package.json`, `.env.example` and `.gitignore`.

Part of [asctane-dashboard](https://github.com/Discord-Dashboard/Core), now in
public beta. Install with `@beta`, for example
`npm install @asctane-dashboard/create@beta`.
