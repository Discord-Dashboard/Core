# @acstane/create

Scaffold a new @acstane/dashboard project.

```bash
npm init @acstane@beta my-bot
```

Creates a discord.js bot with a dashboard: `index.js`, `package.json`, `.env.example` and `.gitignore`.

Part of [@acstane/dashboard](https://github.com/Discord-Dashboard/Core), now in
public beta. Install with `@beta`, for example
`npm install @acstane/create@beta`.
