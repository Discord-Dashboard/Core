# @acstane/platform-discord

Discord support for @acstane/dashboard: OAuth login, the server list, discord.js pickers and the Discord field widgets.

`@acstane/dashboard` includes it. Use it directly when you build a server on `@acstane/core`: pass `discord({ clientId, clientSecret, redirectUri })` in `platforms`.

Part of [@acstane/dashboard](https://github.com/Discord-Dashboard/Core), now in
public beta. Install with `@beta`, for example
`npm install @acstane/platform-discord@beta`.
