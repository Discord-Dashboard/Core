# @asctane-dashboard/platform-discord

Discord support for asctane-dashboard: OAuth login, the server list, discord.js pickers and the Discord field widgets.

`asctane-dashboard` includes it. Use it directly when you build a server on `@asctane-dashboard/core`: pass `discord({ clientId, clientSecret, redirectUri })` in `platforms`.

Part of [asctane-dashboard](https://github.com/Discord-Dashboard/Core), now in
public beta. Install with `@beta`, for example
`npm install @asctane-dashboard/platform-discord@beta`.
