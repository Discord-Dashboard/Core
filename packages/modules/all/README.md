# @asctane-dashboard/modules

Bundle of the reference feature modules.

Installs every reference module: automod, autoresponder, giveaways, leveling, onboarding, reaction roles and tickets.

Part of [asctane-dashboard](https://github.com/Discord-Dashboard/Core), now in
public beta. Install with `@beta`, for example
`npm install @asctane-dashboard/modules@beta`.
