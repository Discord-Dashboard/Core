# @acstane/web

The prebuilt @acstane/dashboard web app: dashboard, page builder and landing page.

Lite mode serves this build on the API port, so you normally don't install it yourself: `@acstane/dashboard` depends on it. Import `webRoot` to serve the files from your own server.

Part of [@acstane/dashboard](https://github.com/Discord-Dashboard/Core), now in
public beta. Install with `@beta`, for example
`npm install @acstane/web@beta`.
