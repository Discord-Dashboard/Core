# @asctane-dashboard/web

The prebuilt asctane-dashboard web app: dashboard, page builder and landing page.

Lite mode serves this build on the API port, so you normally don't install it yourself: `asctane-dashboard` depends on it. Import `webRoot` to serve the files from your own server.

Part of [asctane-dashboard](https://github.com/Discord-Dashboard/Core), now in
public beta. Install with `@beta`, for example
`npm install @asctane-dashboard/web@beta`.
