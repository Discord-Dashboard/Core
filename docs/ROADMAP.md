# Roadmap

Each milestone is a working increment.

- M0 Foundation. Monorepo, protocol, schema, db.
- M1 Auth and lite. Fastify api, Discord OAuth2 with PKCE, generic settings CRUD, in process adapter, web skeleton.
- M2 Bot gateway. WebSocket gateway, sdk-js, example bot.
- M3 Polyglot proof. sdk-py and python example.
- M4 Builder. Puck integration, versioning, safe render.
- M5 AI builder. Structured output, validation loop.
- M6 Monetization. Entitlements, Stripe Connect, Discord SKUs.
- M7 Modules and platform. Reference modules, marketplace, multi tenant.
